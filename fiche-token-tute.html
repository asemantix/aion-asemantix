😰 Le problème aujourd'hui
Vous êtes en voyage. Vous devez accéder à vos fichiers depuis un ordinateur qui ne vous appartient pas. Problème : cet ordinateur peut être espionné, infecté, ou contrôlé.

Si vous tapez votre mot de passe dessus, il peut être volé.
✨ La solution : le Token
Une petite clé USB intelligente que vous gardez sur vous.

Vous la branchez sur n'importe quel ordinateur. Vous tapez votre code sur la clé (pas sur l'ordinateur). Votre environnement apparaît. Vous travaillez. Vous débranchez. Tout disparaît.

L'ordinateur n'a jamais vu vos mots de passe.
📍 Exemple concret
Vous êtes dans un cybercafé à Bangkok. Vous branchez votre Token. Votre bureau apparaît avec tous vos fichiers. Vous répondez à vos emails. Vous débranchez. L'ordinateur du café ne garde rien. Comme si vous n'aviez jamais été là.
